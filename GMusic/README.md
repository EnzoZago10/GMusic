# GMusic

Projeto React Native + Expo SDK 57 reconstruído a partir do tutorial fornecido.

## Executar

```bash
npm install
npm run start
```

Para abrir no navegador:

```bash
npm run web
```

## Assets

O tutorial referencia imagens e áudios próprios em `assets/img` e `assets/audio`, mas esses arquivos originais não foram enviados junto com o HTML.

Para manter o projeto completo e sem referências quebradas, este pacote contém:

- capas substitutas geradas localmente com os mesmos nomes esperados;
- MP3s silenciosos substitutos com os mesmos nomes esperados;
- ícone, adaptive icon, favicon e splash substitutos.

Basta substituir esses arquivos pelos originais, preservando exatamente os nomes e caminhos. O código não precisa ser alterado.
